### 🚀 My Projects

Here are the projects I have completed so far, along with some of the things I learned from each one.

- 📞 **[Telco Customer Churn Prediction](https://github.com/kunkorun/telco-customer-churn-prediction)** — My first business-oriented classification project. I explored how churn relates to contract type, tenure and monthly charges, built a classification baseline, and used cross-validation to evaluate model performance. This project helped me connect classification metrics with a customer-retention problem.

- 🛒 **[Olist E-Commerce — SQL & Data Analysis](https://github.com/kunkorun/Olistproject)** — My first project working with a relational database. I created a PostgreSQL schema for nine related tables, checked the imported data and table relationships, and used SQL to investigate sales trends, delivery delays and repeat purchases. I also used Python and Matplotlib to visualize the results.

- 🚲 **[Bike Sharing Demand](https://github.com/kunkorun/Forecasting-bike-sharing-demand-using-gradient-boosting)** — My first project focused on time-dependent data. I worked with temporal features, chronological validation, target transformation, model comparison, hyperparameter tuning and residual analysis. **Kaggle Score: 0.39975**

- 🔢 **[Digit Recognizer](https://github.com/kunkorun/Digit-Recognizer-solution-using-Random-Forest)** — My first project working with image data. I used Random Forest, cross-validation, hyperparameter tuning, confusion matrices and visual error analysis. **Kaggle Score: 0.96550**

- 🚀 **[Spaceship Titanic — CatBoost Solution](https://github.com/kunkorun/Spaceship-Titanic-solution-using-CatBoost)** — This project helped me start thinking more about the relationships between features when dealing with missing values. I also used CatBoost for the first time and worked on debugging data types and the preprocessing pipeline. **Kaggle Score: 0.80032**

- 🏠 **[House Prices — Advanced Regression](https://github.com/kunkorun/housing-price-prediction)** — Regression project with EDA, feature engineering, target transformation and cross-validation. **Kaggle RMSLE: 0.12444**

- 🚢 **[Titanic — Survival Prediction](https://www.kaggle.com/competitions/titanic)** — My first end-to-end classification project. I worked on EDA, feature engineering, model comparison and validation. **Kaggle Score: 0.77990**
